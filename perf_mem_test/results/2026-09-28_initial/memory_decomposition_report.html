ptnrd vs ptdn 差异：NRD 用 10 张持久 history 纹理 + ~8 张 transient 纹理（~110MB GPU），而 OptiX 只用 5 个 staging buffer + flat stateBuffer（~75-100MB）。但实测 ptnrd 比 ptdn 多 +637MB 全在 CPU 侧——NRD SDK 闭源二进制（shader bytecode + 内部表）占用大量 RSS，远超 OptiX。

5. ncr = NeuralRadiosity

NCR 渲染图只有 NeuralRadiosity + ToneMapper，不含 PathTracer pass。但 NCR pass 内部自实现 path tracing（ConeTrace.cs.slang / FirstSmoothPass.cs.slang / SampleRHS.cs.slang 调用 traceRay），用硬编码 EmissiveUniformSampler（非 RTXDI）。

8. 结论

  • 共享部分占大头：BLAS + 材质纹理 + 几何缓冲 ~1GB，三算法相同，是内存基线。
  • ptdn 最省：OptiX 去噪用 AI 模型压缩时序状态到 flat buffer，无显式 history 纹理，专属仅 ~90MB GPU。
  • ptnrd 比 ptdn 多 +637MB 全在 CPU：NRD 闭源 SDK 的 shader bytecode + 内部表占大量 RSS；GPU 侧仅多 ~35MB（history 纹理 vs staging buffer 几乎抵消）。
  • ncr 专属最大：RayBatch 缓冲 ~486MB 是最大块（每像素 364B × 1280×720），加上 CUDA hashgrid+MLP+optimizer ~158MB。这是为训练数据采集和推理付出的代价。
  • RTXDI 是 CPU 大户：+1157MB CPU RSS（SDK context），GPU 仅 +175MB。仅 ptdn/ptnrd 受影响，ncr 不用 RTXDI 完全不受影响。
  • 公平对比（rtxdi_off）下 ncr 内存超标：ncr 专属 ~770MB vs ptdn ~90MB，多 ~680MB，超过 +200MB 预算。主要来自 RayBatch 设计（每像素全量缓冲）。
